# Reasoner training pipeline

Fine-tunes **Llama-3.1-13B** into the SemantOS guarded reasoner through the
five stages in `config.yaml`. The stages build on each other:

1. **Domain SFT** — learn the output schema and the typed-edge grammar.
2. **Graph-grounding SFT** — condition on the retrieved typed neighborhood so
   the model co-tunes along `SYNERGIZES_WITH` edges and avoids `CONFLICTS_WITH`
   pairs. Ablating this stage reproduces the `wo_depgraph` row of Table 3.
3. **Uncertainty calibration** — fit reported `uncertainty` to realized
   self-consistency disagreement (k=3), so the downstream conformal safety
   runtime is well-calibrated.
4. **DPO safety** (`beta_DPO = 0.1`) — prefer SLO-safe bundles, using
   `outcome.slo_safe` from the dataset to form preference pairs.
5. **Guardrail distillation** — abstain (empty recommendation set) when
   telemetry is healthy or evidence is weak.

## Data

Generated by `data/generate_pairs.py` (1000 workload×hardware pairs). Whole
entities are held out for the generalization study: the **audio** workload and
the **S3** server never appear in `train`/`val`.

```bash
python data/generate_pairs.py --n 1000            # writes data/pairs.jsonl
python kb/induce_edges.py --out kb/seed_edges.json # typed graph used in prompts
```

## Run

The pipeline is config-driven; wire `config.yaml` into your trainer of choice
(e.g. TRL for SFT/DPO). Evaluation reports the Table 3 ablation, held-out
generalization (audio/S3), and uncertainty ECE, and gates on
`min_heldout_slo_safe_rate` and `max_uncertainty_ece`.

## Serving

With `export_gguf: true` the final checkpoint is exported (q4_K_M) for the
Ollama-served runtime; set `OLLAMA_MODEL` in `reasoner`'s environment to the
resulting tag. If `OPENAI_API_KEY` is set instead, the reasoner uses the hosted
model and this local checkpoint is optional.

> The offline reproduction in `reproduce/` does **not** require this trained
> model: it reproduces every paper table/figure from the calibrated response
> model. This pipeline is for standing up the *live* reasoner service.
