\section{Ethical and Responsible Deployment}
\label{sec:ethics}
The new measurements run local software workloads and collect no participant data. No human study or IRB approval is claimed in this revision. The current runtime performs no kernel writes. Future interventions require an isolated testbed, documented rollback limits and appropriate authorization. Human studies, if pursued, require prospective institutional review as applicable and informed consent; these cannot be inferred from software tests.

An AI coding assistant assisted this revision's code, prose and analysis. Measurement provenance, source hashes and explicit evidence limits are retained for author verification. Generated values are not substituted for unavailable observations.
