\begin{abstract}
We present SemantOS, a prototype control loop that combines eBPF telemetry,
typed dependency knowledge, and a guardrailed large language model for
explainable kernel-tuning recommendations. The model has no direct write
authority: a separate runtime validates typed multi-knob transactions, stages
accepted changes, monitors explicit service-level-objective (SLO) guards, and
rolls back on violations. This revision defines a provenance-first evaluation
protocol rather than reporting measurements whose raw hardware logs cannot be
independently traced. The protocol uses disjoint workload-family splits,
like-for-like rules, Bayesian-optimization, reinforcement-learning, LLM-only,
and graph-plus-LLM baselines, and run-level latency, throughput, anomaly,
veto, and rollback outcomes. We make no formal drift-safety guarantee; the
runtime mechanisms are defenses whose effectiveness must be established
empirically on held-out workloads.
\end{abstract}

\textbf{Keywords.} knowledge representation; kernel tuning; explainable control; safety runtime; experimental provenance
